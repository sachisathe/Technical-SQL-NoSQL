SQL and NoSQL Database Project

📌 About Project
This project contains two parts:
MySQL – Employee and Manager relationship using a Self Join.
MongoDB – Performing CRUD operations.

🛢️ MySQL – Employee & Manager
This section demonstrates a self-referencing relationship in MySQL, where an employee is connected to their manager using a Self Join.

🍃 MongoDB – CRUD Operations
The MongoDB file contains basic CRUD operations:
Create – Insert data
Read – Find data
Update – Modify data
Delete – Remove data

🛠️ Technologies Used
SQL - MySQL
NoSQL - MongoDB
